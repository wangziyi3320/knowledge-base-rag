# 内部 IT 服务指南（虚构示例）

## 密码与账号

员工忘记系统密码时，应先在统一身份平台使用自助重置功能。自助重置失败时，通过服务台提交账号支持工单，并提供员工编号和系统名称。服务台核验身份后处理，任何人不得在工单评论中发送明文密码。

新员工账号由直属负责人在入职流程中发起申请。账号开通后，申请人会收到平台通知。离职账号由人事流程触发停用，业务负责人负责确认共享资料的交接情况。

## 远程接入

访问内部开发环境需要先提交 VPN 权限申请，直属负责人审批后由 IT 配置权限。申请时应填写访问目的、目标系统和预计使用期限。连接失败时先检查客户端版本与网络状态，再提交服务台工单并附上错误截图。

VPN 权限按最小权限原则发放。临时访问结束后，申请人应及时关闭访问权限。访问目的变化时，需要重新确认权限范围。

## 设备维修

电脑无法启动时，先断开外接设备并检查电源连接。问题仍存在时，通过服务台提交设备维修工单，填写资产编号、故障现象和可联系时间。IT 收到工单后会安排现场检查，未经确认不要自行拆卸公司设备。

维修完成后，申请人需要确认设备恢复正常，并在工单中填写处理反馈。设备报废和更换属于另外的资产流程，维修工单不会自动批准采购新设备。
